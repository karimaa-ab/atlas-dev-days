# Atlas Dev Days

> Site vitrine pour la première édition des **Atlas Dev Days**, une conférence de deux jours dédiée aux développeurs web au Maroc (5-6 Octobre 2026).

## 🚀 Fonctionnalités & Pages

Le site comporte 4 pages reliées par une navigation commune :
1. **Accueil (`index.html`)** : Section hero, chiffres clés, présentation de l'événement et aperçu des intervenants.
2. **Programme (`programme.html`)** : Les deux journées de conférences et d'ateliers avec les horaires et thèmes.
3. **Intervenants (`intervenants.html`)** : Cartes détaillées des différents intervenants de la conférence.
4. **Inscription (`inscription.html`)** : Formulaire d'inscription complet avec validation native (HTML5) et informations pratiques.

---

## 🛠️ Stack Technique

- **HTML5 Sémantique** (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **CSS3 Natif** (Variables CSS `:root`, Flexbox pour toutes les mises en page)
- **Design System** : Maquettes Desktop (1440px) et Mobile (375px) sous **Figma**
- **Versionning** : Git & GitHub
